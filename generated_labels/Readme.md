This directory contains the generated urban opportunity indicator data used in the manuscript.

(1) Phoenix_city_task_prompts.csv: example task prompt

(2) train.csv:  training data (40 cities)

(3) seen_city_test.csv:   test data, Seen City-Unseen Indicator

(4) unseen_city_test.csv: test data, UnSeen City-Unseen Indicator

(5) unseen_city_seen_indicator_test.csv: test data, UnSeen City-seen Indicator
