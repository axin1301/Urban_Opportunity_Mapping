This directory contains the generated urban opportunity indicator data (UrbanOpp Benchmark) used in the manuscript.

(1) Phoenix_city_task_prompts.csv: example task prompt

(2) train_sample_1pct.csv:  training data (40 cities, Due to space limitations, only a 1% sample of the original dataset is included.)

(3) seen_city_test.csv:   test data (10 cities), Seen City-Unseen Indicator

(4) unseen_city_test.csv: test data (10 cities), UnSeen City-Unseen Indicator

(5) unseen_city_seen_indicator_test_sample_1pct.csv: test data (10 cities), UnSeen City-seen Indicator (Due to space limitations, only a 1% sample of the original dataset is included.)
